# 👻 명패봇 (NameCardMaker)

회의용 명패를 **엑셀에서 복사 → 붙여넣기 → 인쇄**만으로 만드는 웹 도구입니다.
설치·서버 없이 `index.html`만 열면 동작합니다. (사내 IIS 등 정적 호스팅에도 그대로 올릴 수 있음)

## 사용법

1. 엑셀에서 명단 범위를 드래그해 복사(`Ctrl+C`)
2. 명패봇 왼쪽 **① 붙여넣기** 칸에 `Ctrl+V` → 오른쪽에 명패가 즉시 생성
3. **② 명단 확인·수정**에서 오타 수정, 행 추가/삭제
4. **③ 디자인**에서 색상·방식·글자 크기 조절
5. **🖨 인쇄 / PDF 저장** → 인쇄 창에서 용지 **A4**, 배율 **100%**

### 입력 형식

| 상황 | 인식 방식 |
|---|---|
| 첫 줄에 `회사/이름/직급`(또는 `Company/Name/Position`, 소속·성명·직책 등) 제목이 있음 | 제목으로 열을 찾음 → **열 순서가 달라도 OK** |
| 제목 없음, 3열 | 회사 · 이름 · 직급 순 |
| 제목 없음, 2열 | 이름 · 직급 순 |
| 제목 없음, 1열 | 이름만 |

- 엑셀 복사(탭 구분), CSV(쉼표 구분), 공백으로 띄운 텍스트 모두 붙여넣기 가능
- CSV 파일은 **CSV 열기** 버튼 또는 화면에 끌어다 놓기. 인코딩(UTF-8 / EUC-KR)은 자동 감지
- 공백 구분 입력은 `이름 직급`처럼 단어가 하나씩일 때만 정확합니다. 회사명에 띄어쓰기가 있으면 엑셀 복사를 쓰세요.

### 기능

- **접이식 양면**: A4 1장에 2명. 위쪽 면은 180° 회전되어 있어, 반으로 접어 세우면 양쪽에서 똑바로 읽힙니다.
- **단면**: A4 1장에 4명 (벽걸이·스티커·스탠드용)
- **디자인 3종**: 클래식(4색 띠) / 단색 / 줄 없음(잉크 절약)
  - **단색**: 띠를 한 가지 색으로. 팔레트 14색에서 고르거나, 색상 선택기로 원하는 색을 직접 지정
- **글자 자동 맞춤**: 긴 이름·회사명·직급은 칸에 맞게 자동으로 작아짐. 전체 크기는 60~120% 조절
- **회사명 일괄 입력**: 전원 같은 회사일 때 한 번에 적용 (회사명 표시 끄기도 가능)
- **자동 저장**: 명단·설정은 이 브라우저(localStorage)에만 저장. 서버 전송 없음 → 개인정보 안심
- 표 칸에서 `Enter` = 아래 칸 이동(마지막 행이면 새 행), 표 안에 엑셀 범위를 붙여넣으면 그 위치부터 채움

## 파일 구성

```
index.html      화면
css/style.css   화면·인쇄 스타일 (A4, 여백 0은 @page로 자동 처리)
css/fonts.css   내장 글꼴(나눔스퀘어 네오, base64) — 자동 생성 파일
fonts/          글꼴 원본(woff2) + 출처·저작권 안내
tools/embed_font.py   fonts/ 의 글꼴을 css/fonts.css 로 다시 내장 (글꼴을 바꿀 때만 실행)
js/app.js       로직 (외부 라이브러리 없음)
sample/명단_예시.csv   테스트용 샘플 (UTF-8 BOM, 엑셀에서 바로 열림)
sitemap.xml     기존 사이트맵
```

## 알아둘 점

- 명패 글꼴(나눔스퀘어 네오)은 파일 안에 내장되어 있어 **인터넷·폰트 다운로드가 막힌 환경에서도 그대로** 나옵니다. 웹서버의 `.woff2` MIME 설정이 없어도(IIS 등) 동작합니다.
- 외부 연결이 전혀 없습니다. (글꼴·스크립트·광고 모두 내장 또는 제거)
- 인쇄 시 배경 그래픽은 코드에서 강제로 켭니다. 그래도 색 줄이 안 나오면 인쇄 창의 "배경 그래픽" 옵션을 확인하세요.
